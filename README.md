# SKYBREAK

スマホ横向き前提のオリジナル・プラットフォームファイター開発リポジトリです。

現在は完成版の製造前に、**戦闘基盤の品質を固めるフェーズ**です。

## 現在の操作

- 左スティック: 移動
- JUMP: ジャンプ / 2段ジャンプ
- A: 通常攻撃
- B: 必殺弾
- PORTAL: KDKGamesへ戻る

## ポータル上のカテゴリ

`ACTION`

ゲーム本体は容量増加を考慮して `KDKGames` とは別リポジトリで管理し、ポータル側には軽量ランチャーのみ配置します。

詳細な開発方針・仕様・完了条件は [DEVELOPMENT.md](./DEVELOPMENT.md) を参照してください。
